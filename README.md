# Memory

Социальная сеть для Android на Kotlin и Jetpack Compose: лента, чаты, профиль.
Тёмная «космическая» тема в фиолетово-синей гамме.

## Что уже есть

- **Заставка.** После нажатия на значок на фоне кристалла появляется слово
  **MEMORY** из атомов. Два режима, переключаются константой `SPLASH_MODE`
  в `ui/splash/AtomSplash.kt`:
  - `Dissolve` — слово рассыпается на атомы, начиная с последней буквы;
  - `Assemble` — слово собирается из атомов, начиная с первой.

  Нажатие пропускает заставку. Физика — `ui/splash/AtomField.kt`.
- **Три вкладки**: Лента · Чаты · Профиль, парящая стеклянная панель внизу.
  - **Лента**: можно опубликовать запись и поставить «нравится».
  - **Чаты**: поиск, счётчик непрочитанных, переписка. Демо-собеседник
    «печатает» и отвечает.
  - **Профиль**: аватар, счётчики, свои записи, редактирование имени
    и «о себе», настройки.
- **Значок приложения** — кристалл (адаптивный значок, `mipmap-*`).

Сервера пока нет: данные выдуманы и живут в памяти (`data/Demo.kt`). Экраны
работают с моделью так же, как будут работать с настоящим API.

## Дизайн

| Цвет | HEX | Где |
|---|---|---|
| Lilac | `#BC92CD` | акценты, выбранная вкладка |
| Orchid | `#844CAD` | кнопки, градиенты |
| Violet | `#5F3F96` | свои сообщения |
| Plum | `#3C2C59` | стеклянные карточки |
| Night | `#0F153A` | фон |
| Ocean | `#195699` | градиенты |
| Sky | `#307EC0` | индикаторы, «в сети» |

Шрифты: **Unbounded** (заголовки, MEMORY) и **Inter** (текст). Оба под
лицензией OFL, с кириллицей; лицензии лежат в `docs/licenses/`.
Значки — свои тонкие линейные (`ui/components/LineIcons.kt`): они
подходят к тонкому шрифту лучше, чем залитые значки Material.

## Сборка и выпуск

Ветки `main` / `develop` / `feature/*`, проверки на каждый PR, тестовая
сборка после каждого слияния в `develop` и выпуск по тегу `vX.Y.Z` описаны
в [docs/CICD.md](docs/CICD.md), правила работы — в
[CONTRIBUTING.md](CONTRIBUTING.md).

**Свежая тестовая сборка** — выпуск **dev** на GitHub:
`releases/download/dev/memory-dev.apk`.

**Android Studio.** Откройте папку проекта и нажмите Run.

**Командная строка** (нужны JDK 17 и Android SDK):

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # юнит-тесты
```

Отладочная сборка ставится как `ru.wishka.memory.debug` — рядом с будущей
рабочей.

## Устройство

```
app/src/main/java/ru/wishka/memory/
  MainActivity.kt          заставка → вкладки, системное «назад»
  data/                    модели и демо-данные
  ui/AppViewModel.kt       состояние приложения
  ui/theme/                палитра, шрифты, тема
  ui/splash/               заставка MEMORY → атомы
  ui/components/           фон-космос, стекло, панель вкладок, значки
  ui/feed/  ui/chats/  ui/profile/   экраны вкладок
app/src/test/              юнит-тесты (заставка, модель)
.github/workflows/         CI, dev-сборка, выпуск
scripts/                   настройка GitHub, ключи подписи
```

Навигация — как в angelsheart: своё состояние в модели, без библиотеки
навигации.
