# Сеть: API, офлайн, загрузки

Как Memory говорит с сервером и что делает без сети. Точный контракт —
[openapi.yaml](openapi.yaml).

Всё, что не зависит от платформы, проверяется тестами (`Round22Test`,
`Round22Tests`) прямо против демо-сервера: страницы без пропусков и
повторов, обрыв загрузки посреди куска и продолжение после «перезапуска»,
повтор отправки без дублей, порядок сообщений.

## Сервер

- **Пока сервера нет** — встроенный демо-сервер отвечает по тому же
  контракту: 150 старых записей друзей для ленты, публикация, «нравится»,
  переписка, загрузки tus. Живёт, пока открыто приложение.
- **Подключить свой** — адрес в `local.properties` (`api.url=https://…`) и
  `ios/Memory/Secrets.plist` (`API_URL`), в CI — секрет `API_URL`. Пусто —
  демо. Токен входа — `Authorization: Bearer …` (подключается вместе с
  входом через сервер).
- Загрузки: подойдёт готовый [tusd](https://github.com/tus/tusd) за тем же
  адресом `/v1/uploads` (или любой сервер tus 1.0 с расширением creation).

## Без сети

- **Сохранённое.** Лента (до 100 последних записей с сервера) лежит в
  SQLite — открывается мгновенно и без сети; внизу ленты — «Нет сети —
  дальше загрузим, когда появится». У каждого аккаунта своя база
  (`net-<логин>.db`).
- **Очередь отправки.** Запись, «нравится», сообщение видны сразу; на
  сервер уходят по очереди, когда есть сеть. У записи — «Ждёт сети» или
  «Отправляется · 45 %», у сообщения — 🕓. Каждое действие несёт
  `Idempotency-Key`: если ответ потерялся и очередь повторит, дубля не
  будет. Сообщения в одной переписке не обгоняют друг друга. «Нравится»
  к одной записи схлопываются — уходит последнее нажатие.
- **Повторы.** Нет сети, таймаут, 5xx, 429 — повтор через 1, 2, 4… с (не
  реже раза в 5 минут, `Retry-After` главнее). Сеть вернулась — сразу, без
  накопленной паузы. 4xx — не повторяем: запись остаётся на телефоне, а
  в ленте — объяснение.
- **Полоска сверху:** «Нет сети — показываем сохранённое» / «Сервер не
  отвечает — попробуем ещё» и сколько ждёт отправки.

## Фото и видео

1. **Сжатие** перед отправкой — копия в кэше приложения, оригинал не
   трогаем. «Настройки → Данные и сеть»:
   - **Стандартное** — фото до 2048 точек (JPEG 82 %), видео 720p ~2,5 Мбит/с;
   - **Экономия трафика** — 1280 точек (75 %), 480p ~1,2 Мбит/с;
   - **Оригинал по Wi‑Fi** — по Wi‑Fi без сжатия, в мобильной сети — как
     «Стандартное».
   Поворот снимка «впекается» в пиксели; гифки и стикеры не трогаем; если
   сжатое вышло тяжелее исходного — уходит исходное.
2. **Загрузка по tus**: кусками по 1 МБ. После каждого куска смещение
   сохраняется; оборвалось — на HEAD сервер отвечает, сколько дошло, и
   загрузка продолжается оттуда же, в том числе после перезапуска. Пауза,
   продолжение и отмена — в «Данных и сети».
3. **Запись или сообщение** уходят, когда загрузились все их вложения:
   пути файлов заменяются адресами загрузок.
