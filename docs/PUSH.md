# Уведомления и пуши

Memory пишет уведомления не «Вы давно не заходили», а про то, что важно
именно вам:

- «Ваша подруга Вера только что отметила фильм «Дюна», который вы обсуждали»
- «В вашей группе «Ночное небо» новый участник — Мария»
- «Тимур пробежал 7 км. У вас за месяц — 12 км, не отставайте!»
- «Итоги: Сентябрь 2026 — 4 фильма, 23 км. Посмотрите, каким был ваш месяц»

Тексты собирает одно место — `Nudges` (`data/Nudges.kt`,
`Data/Nudges.swift`). «Обсуждали» — название фильма, книги или места
встречается в ваших записях, комментариях или сообщениях.

## Как это работает сейчас (без сервера)

Сервера у Memory пока нет, поэтому уведомления **локальные**: приложение
само собирает их из событий.

- Пока приложение открыто — стеклянная плашка сверху.
- Свёрнуто — системное уведомление (Android: свой канал на каждый раздел;
  iPhone: UNUserNotificationCenter).
- У каждого вида — свой звук Memory (`data/Sounds`): сообщения — «Кристалл»,
  PRISM — «Призма», лайки — «Звёздная пыль», подписки — «Орбита», группы —
  «Луна», друзья — «Комета», итоги — «Туманность». Поменять — «Настройки →
  Уведомления → Звуки». На Android звук задаётся каналом, поэтому id канала —
  вид + звук (`memory_messages_crystal`); при смене звука канал
  пересоздаётся. Плашка в открытом приложении звучит тем же звуком.
- Нажатие открывает то, о чём уведомление: ленту, группу, страницу
  человека, переписку, Итоги или заявки.
- Выключатели — «Настройки → Уведомления»: сообщения, PRISM друзей,
  лайки, подписки, группы, друзья, итоги.

События в демо приходят раз в 1–2,5 минуты, пока приложение живо: друзья
отмечают чек-ины (фильмы, книги, пробежки, места), в группы приходят люди,
вашим записям ставят «нравится», при закрытом профиле приходят заявки.
Уведомление об итогах прошлого месяца — один раз в начале месяца, об итогах
года — в январе.

## Пуши с сервера

Сервер Memory (`server/`, `Push.kt`) присылает **факты, а не готовый
текст** — текст складывается на телефоне, на языке интерфейса. Сейчас он
шлёт: `message` (кто не на связи по живому каналу; у секретной переписки —
без текста), `follow_request`, `new_follower`, `request_accepted`,
`comment` (`postId`, `body`). Остальные типы таблицы — когда эти события
переедут на сервер.

### Данные пуша

| Ключ | Пример | Зачем |
|---|---|---|
| `type` | `friend_checkin`, `group_member`, `follow_request`, `request_accepted`, `message`, `prism` | что случилось |
| `actor`, `actorId` | `Вера Лунная`, `2` | кто |
| `activity` | `movie`, `book`, `run`… или свой `custom-…` | чек-ин |
| `subject`, `amount` | `Дюна`, `7` | что именно и сколько |
| `discussed` | `1` | сервер нашёл это в ваших разговорах |
| `myKm` | `12` | ваши километры за месяц |
| `group`, `groupId` | `Ночное небо`, `1` | группа |
| `common` | `Фото,Кино` | общие интересы |
| `chatId`, `body` | `3`, `Привет!` | сообщение (пустой `body` — «Новое сообщение») |
| `postId`, `body` | `10000001`, `Класс` | комментарий к вашей записи |
| `prismId`, `caption` | `42`, `Огни Невы` | новый PRISM друга |
| `title`, `body` | — | запасной вариант для неизвестного `type` |

Сервер сам учитывает выключатели уведомлений человека.

### Android — Firebase Cloud Messaging

1. Создайте проект в [Firebase](https://console.firebase.google.com) и
   добавьте Android-приложение `ru.wishka.memory` (и `ru.wishka.memory.debug`
   для отладочных сборок).
2. Из `google-services.json` возьмите четыре значения. Плагин
   google-services не нужен — ключи приходят через BuildConfig.
   - локально — в `local.properties`:
     ```
     firebase.appId=1:1234567890:android:abcdef
     firebase.apiKey=AIza...
     firebase.projectId=memory-xxxx
     firebase.senderId=1234567890
     ```
   - в GitHub — секреты репозитория `FIREBASE_APP_ID`, `FIREBASE_API_KEY`,
     `FIREBASE_PROJECT_ID`, `FIREBASE_SENDER_ID` (workflow передают их в
     сборку).
3. Без ключей FCM не запускается, работают только локальные уведомления.
   Отладочные сборки (CI, dev, demo) — это `ru.wishka.memory.debug`:
   зарегистрируйте его в Firebase тоже, либо не ограничивайте API-ключ
   одним приложением.
   Сервер шлёт **data-сообщения** (без блока `notification`): тогда текст
   собирает приложение, учитывает выключатели уведомлений и знает, что
   открыть по нажатию. Сообщения с `notification` система покажет сама в
   запасном канале `memory_default` (звук «Кристалл»); свой звук вида они
   не получат — поэтому data-сообщения.
4. Токен устройства хранится в `PushTokens` (`push/PushSetup.kt`) и
   после входа уходит на сервер: `PUT /v1/devices/current/push`. Вышли с
   телефона — устройство и его токен на сервере удаляются.
5. **Сервер**: ключ сервисного аккаунта Firebase → `server/secrets/firebase.json`
   (Firebase → ⚙ Настройки проекта → **Сервисные аккаунты** → **Создать
   закрытый ключ**). Папка `server/secrets/` в `.gitignore`. Перезапуск —
   `docker compose up -d`; в логе сервера — «Пуши: FCM». Нет файла — пуши
   выключены, остальное работает. Токены удалённых приложений (FCM:
   `UNREGISTERED`) сервер забывает сам.
6. Приёмник — `push/MemoryMessagingService.kt`: data-пуш превращается в
   текст через `Nudges.fromPush`.

### iPhone — APNs

> Пока не подключено к серверу: для APNs нужен платный Apple Developer
> ($99 в год), с бесплатным Apple ID пуши на iPhone не работают. Ниже —
> что сделать, когда аккаунт появится.

1. В Xcode: Target **Memory → Signing & Capabilities → + Capability →
   Push Notifications** (и **Background Modes → Remote notifications**
   для тихих пушей). Xcode сам создаст файл entitlements.
2. В Apple Developer создайте ключ APNs (.p8) — он нужен серверу.
3. Токен устройства — `PushCenter.shared.token` (`App/Push.swift`).
4. Тихий пуш (`content-available: 1`) с данными из таблицы выше —
   приложение само соберёт текст и покажет уведомление со звуком своего
   вида. Обычный пуш с `alert` показывает система; данные в нём нужны,
   чтобы нажатие открыло нужный экран, а звук сервер указывает сам:
   `"sound": "snd_crystal.wav"` (файлы лежат в приложении,
   `ios/Memory/Sounds`; имена — `snd_` + id звука из `data/Sounds`).

Без возможности Push Notifications регистрация в APNs просто не проходит:
локальные уведомления работают и так.
