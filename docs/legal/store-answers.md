# Ответы для анкет магазинов

Черновик ответов для App Store Connect (App Privacy) и Google Play Console (Data safety). Сверяйте с тем, что действительно делает сборка, которую отправляете: сейчас (без сервера) данные почти не покидают телефон, с сервером ответы меняются — колонка «С сервером».

## App Store — App Privacy

| Тип данных (Apple) | Сейчас | С сервером | Связано с человеком | Для слежки |
| --- | --- | --- | --- | --- |
| Contact Info → Name | не собирается | да, функциональность | да | нет |
| Contact Info → Phone Number | не собирается | да, функциональность | да | нет |
| Contact Info → Email Address (восстановление доступа) | не собирается (письма — демо) | да, функциональность | да | нет |
| User Content → Photos or Videos, Audio, Other | не собирается | да, функциональность | да | нет |
| User Content → Messages | не собирается | да, функциональность | да | нет |
| Location → Precise Location | не собирается | да, функциональность (только когда человек делится местом) | да | нет |
| Identifiers → Device ID (токен пушей) | да, функциональность | да | нет | нет |
| Search History (поиск GIPHY, медиатека) | да, третьим сторонам для функциональности | да | нет | нет |
| Diagnostics → Crash Data | да, функциональность — только с согласия в «Приватности» (Sentry, если в сборке есть ключ) | то же | нет | нет |
| Usage Data → Product Interaction | да, аналитика — только с согласия (счётчики раз в день, без текстов) | то же | нет | нет |

Tracking: нет (App Tracking Transparency не нужен). Возрастной рейтинг: 16+ (пользовательский контент, переписка). Покупок в приложении сейчас нет — Memory бесплатен.

Страна запуска — Армения. Описание в магазинах — на армянском (основное), русском и английском; ссылки на документы — армянские версии ([https://сайт-memory]/legal/privacy.hy).

## Google Play — Data safety

- Собираются ли данные: «Да» (токен пушей, поисковые запросы; с сервером — всё из таблицы выше).
- Передаются третьим лицам: поисковые запросы — GIPHY, Jamendo, Openverse (для работы функции); отчёты о сбоях и статистика — Sentry, **только по согласию, необязательные** (App info and performance → Crash logs; App activity → App interactions — «Optional»).
- Сообщения секретных переписок — сквозное шифрование; копию данных можно скачать в приложении («Приватность → Скачать мои данные»).
- Шифрование при передаче: да (HTTPS).
- Можно запросить удаление: да — в приложении и по ссылке [https://сайт-memory]/legal/delete-account.
- Ссылка на политику: [https://сайт-memory]/legal/privacy.hy (армянская), /legal/privacy (русская), /legal/privacy.en (английская).

Жалоба на запись, комментарий, PRISM, сообщение и человека; блокировка; правила сообщества при регистрации; контакт для жалоб [abuse@домен]; разбор жалоб в течение 24 часов, удаление незаконного контента — не позднее 3 дней.
