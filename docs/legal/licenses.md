# Лицензии и авторы

Memory использует чужой труд — спасибо его авторам.

## Карты

- **OpenStreetMap** — данные карт © участники OpenStreetMap, лицензия Open Database License (ODbL). openstreetmap.org/copyright
- **osmdroid** (Android) — Apache License 2.0.
- **Apple MapKit** (iPhone) — карты Apple, условия Apple.

## Гифки и музыка

- **GIPHY** — поиск гифок, Powered by GIPHY; гифки принадлежат их авторам и показываются по условиям GIPHY.
- **Jamendo** — музыка независимых авторов под лицензиями Creative Commons; автор и лицензия указаны у каждого трека.
- **Openverse** — музыка под CC0 и CC BY; автор и лицензия указаны у каждого трека.
- Встроенные гифки Memory нарисованы для Memory (scripts/media_assets.py), 57 звуков уведомлений синтезированы для Memory (scripts/make_sounds.py); мелодии — собственные.
