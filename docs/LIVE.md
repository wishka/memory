# Эфиры, звонки, шифрование, отчёты о сбоях, ссылки

Что в Memory уже работает на телефоне и что подключается вместе с сервером.

## Прямые эфиры (LiveKit)

Сейчас эфиры — **демо**: ведущий видит свою камеру, зрители, сердечки и чат
приходят из демо-жизни, видео никуда не уходит.

Код уже разделён: экран эфира знает только `LiveTransport`
(`data/Live.kt`, `Data/Live.swift`) — `publish(room, token)`,
`join(room, token)`, `leave()`. Сейчас вместо него `DemoLiveTransport`.

Подключение:

1. Поднять сервер [LiveKit](https://livekit.io) (свой или LiveKit Cloud).
2. На сервере Memory — `POST /live/token`: по входу человека выдаёт
   токен комнаты `live-<id>` (ведущему — право публиковать, зрителям —
   только смотреть; эфир «для друзей» — только друзьям).
3. Адрес — `livekit.url=wss://…` в `local.properties` (Android) и
   `LIVEKIT_URL` в `ios/Memory/Secrets.plist`; в CI — секрет `LIVEKIT_URL`.
4. Android: зависимость `io.livekit:livekit-android`, класс
   `LiveKitTransport : LiveTransport` → `vm.liveTransport = LiveKitTransport(...)`.
   iPhone: пакет `client-sdk-swift` (Swift Package Manager в Xcode),
   `LiveKitTransport: LiveTransport`.
5. Экран зрителя вместо демо-картинки показывает видеодорожку ведущего.

## Звонки (LiveKit)

Сейчас звонки — **демо**: экран звонка, кнопки, история звонков,
пропущенные и строка звонка в переписке работают; друг «отвечает» через
пару секунд, голос и видео никуда не уходят. Своя камера в окошке —
настоящая.

Экран знает только `CallTransport` (`data/Calls.kt`, `Data/Calls.swift`):
`connect(room, token, video)`, `setMuted`, `setCamera(on, front)`,
`hangUp()`. Сейчас — `DemoCallTransport`.

Подключение — тот же сервер LiveKit, что у эфиров:

1. На сервере Memory — `POST /calls/token`: комната `call-<id>` на двоих;
   токен выдаётся, только если собеседник разрешил вам звонить
   (`Privacy.calls`: все / друзья / никто) и не заблокировал вас.
2. Входящий звонок — пуш: на Android high-priority FCM с
   `full-screen intent` (foreground service типа `phoneCall`,
   разрешения `CAMERA`, `RECORD_AUDIO`), на iPhone — VoIP-пуш
   (PushKit) + CallKit (`UIBackgroundModes: voip` добавить в Info.plist
   через Xcode, вместе с подключением).
3. `LiveKitCallTransport : CallTransport` → `vm.callTransport = …`;
   вместо демо-картинки собеседника — его видеодорожка.
4. Ответ, отказ, «нет ответа» — события комнаты; `callAnswered()` /
   `callTimeout()` у модели уже есть.

## Сквозное шифрование переписки

Работает уже сейчас (`data/ChatCrypto.kt`, `Data/ChatCrypto.swift`):

- у каждого аккаунта своя пара ключей X25519; закрытый — в зашифрованном
  хранилище телефона (Android Keystore / Keychain), никуда не уходит;
- ключ переписки — HKDF-SHA256 от общего секрета, сообщение — AES-256-GCM;
  конверт `base64(nonce | шифртекст | тег)` одинаков на Android и iPhone;
- «Код безопасности» — 60 цифр из обоих открытых ключей, совпадает у обоих.

С сервером: при регистрации телефон публикует свой открытый ключ, сервер
хранит его и отдаёт собеседникам; сообщения секретных переписок сервер
хранит и пересылает только конвертами. Сейчас ключ собеседника — демо.

Перед запуском стоит заменить X25519 на Android (своя реализация на
BigInteger) на библиотечную с постоянным временем — Tink или libsodium.
На iPhone используется CryptoKit — менять не нужно.

## Отчёты о сбоях и статистика (Sentry)

Только с согласия, отдельно на каждое (по умолчанию выключено) —
«Настройки → Приватность → Сбои и статистика».

- Android: `sentry.dsn=…` в `local.properties` или `SENTRY_DSN`;
  в CI — секрет `ANDROID_SENTRY_DSN`. SDK уже в зависимостях.
- iPhone: `SENTRY_DSN` в `Secrets.plist`, в CI — секрет `IOS_SENTRY_DSN`.
  Пакет `sentry-cocoa` добавляется в Xcode (File → Add Package
  Dependencies → `https://github.com/getsentry/sentry-cocoa`); код
  включится сам (`#if canImport(Sentry)`).
- Без ключа отправка выключена: последний сбой виден в «Приватности».

Что уходит: тип ошибки и где в коде (почта, логины и длинные числа
вырезаются, `Scrub`), раз в день — счётчики событий (`AppEvent`) без
текстов. Сервис — Functional Software, Inc. (Sentry), США: это указано
в политике конфиденциальности.

## Ссылки на запись и профиль

«Поделиться ссылкой» даёт веб-ссылку `https://wishka.github.io/memory/l/?p=…`
(страница `docs/l`, GitHub Pages): она открывает приложение по
`memory://post/…`, а без приложения предлагает его поставить. Внутри
Memory такие ссылки открываются сразу. Пока сервера нет, запись
открывается только на телефоне, где она есть.

## Восстановление доступа

- Коды восстановления (10 штук) — при регистрации и в «Безопасности»;
  хранятся только отпечатками, работают без сервера.
- Почта — подтверждение кодом из письма. Пока сервера нет, писем нет:
  код виден на экране с пометкой «Демо». С сервером `DemoMail` заменяется
  отправкой с сервера (`MailSender`).
