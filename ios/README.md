# Memory для iPhone

Нативное приложение на SwiftUI — то же, что Android-версия: заставка
MEMORY, вход по логину и паролю, Лента · Истории · PRISM · Чаты · Группы ·
Профиль, страница человека, группы. Фото и видео в Ленте и чатах
(галерея или камера), документы в чатах, комментарии, «Поделиться» и
«Сохранить» в PRISM, удаление сообщений у себя или у обоих. Своё
хранится на iPhone (Application Support) и переживает перезапуск. Палитра, шрифты (Unbounded, Inter),
значок и демо-данные — общие с Android.

Нужно: Mac с **Xcode 16 или новее**, iPhone с **iOS 17 или новее**.

## Поставить на свой iPhone по кабелю (бесплатный Apple ID)

1. Откройте проект: `ios/Memory.xcodeproj` (двойной щелчок или
   `open ios/Memory.xcodeproj`).
2. Xcode → **Settings → Accounts → «+» → Apple ID** — войдите своим
   Apple ID. Платный аккаунт разработчика не нужен.
3. Слева выберите проект **Memory** → цель **Memory** → вкладка
   **Signing & Capabilities**:
   - галочка **Automatically manage signing** стоит;
   - **Team** — ваше имя (Personal Team);
   - если Xcode пишет, что идентификатор занят, поменяйте **Bundle
     Identifier** на свой, например `ru.<ваш-ник>.memory`.
4. Подключите iPhone кабелем, разблокируйте и нажмите «Доверять этому
   компьютеру».
5. На iPhone включите **Режим разработчика**: Настройки → Конфиденциальность
   и безопасность → Режим разработчика → Вкл. (телефон перезагрузится).
   Пункт появляется после первого подключения к Xcode.
6. Вверху Xcode выберите свой iPhone вместо симулятора и нажмите **▶ Run**
   (⌘R).
7. Первый запуск iPhone не разрешит: Настройки → Основные → **VPN и
   управление устройством** → ваш Apple ID → **Доверять**. Затем откройте
   Memory ещё раз.

**Геолокация для вкладки «Вместе».** Клады, миссии и вылазки спрашивают,
где вы. Добавьте в Xcode: цель **Memory** → **Info** → «+» → ключ
**Privacy - Location When In Use Usage Description**
(`NSLocationWhenInUseUsageDescription`) с текстом, например «Чтобы
показывать клады, миссии и вылазки рядом с вами». Без этого ключа iOS не
покажет запрос, и вкладка будет писать, что не удалось узнать, где вы.

**Ссылки-приглашения.** Чтобы `memory://invite?…` открывала приложение,
добавьте схему: цель **Memory** → **Info** → **URL Types** → «+» →
**URL Schemes**: `memory` (Identifier — например `ru.wishka.memory.invite`).

Вход без регистрации: логин `demo`, пароль `memory2026`.

**Ограничения бесплатного Apple ID:** приложение работает **7 дней**, потом
iPhone перестаёт его открывать — подключите телефон и снова нажмите ▶ Run
(данные сохранятся). Одновременно можно держать до трёх своих приложений.

## Без iPhone — на симуляторе

Выберите вверху любой iPhone-симулятор и нажмите ▶ Run. Тесты — ⌘U.

## Устройство проекта

```
ios/
├── Memory.xcodeproj        проект Xcode (папки подключаются сами: новый
│                           файл в Memory/ сразу попадает в сборку)
├── Memory/
│   ├── App/                точка входа, заставка → вход → приложение
│   ├── Theme/              палитра и шрифты
│   ├── Data/               модели, демо-данные, вложения, сохранение
│   │   └── Auth/           вход: PBKDF2, хранилище, Связка ключей
│   ├── UI/
│   │   ├── Splash/         атомы, кристальное слово, небо
│   │   ├── Components/     стекло, аватар, значки, кнопки, панель вкладок
│   │   ├── Feed/ Stories/ Prism/ Chats/ Groups/ Person/ Profile/ Auth/
│   │   ├── Together/       вкладка «Вместе»: цели, навыки, карты, рисунок, обмен
│   │   ├── AppModel.swift  состояние и правила приложения
│   │   └── MainScreen.swift
│   ├── Fonts/              Unbounded, Inter (OFL)
│   ├── Assets.xcassets     значок, цвета, кристалл для шапки
│   └── Info.plist          экран запуска и тексты запросов камеры, микрофона, геолокации
└── MemoryTests/            юнит-тесты: заставка, вход, правила приложения
```

Swift-файлы повторяют Kotlin-файлы Android-версии по именам и правилам:
`AtomField.swift` ↔ `AtomField.kt`, `LocalAuth.swift` ↔ `LocalAuth.kt`,
`AppModel.swift` ↔ `AppViewModel.kt`. Меняете правило в одной версии —
поменяйте и в другой; тесты в обеих проверяют одно и то же.

## Безопасность входа

- Пароль не хранится: только соль и ключ PBKDF2-HMAC-SHA256,
  120 000 итераций (CommonCrypto). Сравнение — за постоянное время.
- Сессия — в Связке ключей (`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`),
  не уезжает в резервные копии на другие устройства.
- После 5 неверных попыток вход по логину закрыт на 30 секунд.
- Аккаунты пока живут только на этом iPhone — сервера ещё нет.

## CI

`.github/workflows/ios.yml` — на macOS-машине GitHub: сборка, юнит-тесты на
симуляторе и проверочная сборка под iPhone без подписи. Запускается, когда
меняется `ios/`.
